# Sport Mate - Backend

## Overview

The backend provides API services for the Sport Mate sportswear e-commerce mobile application.

## Technology Stack

- ASP.NET Core Web API
- .NET 8
- Entity Framework Core
- JWT Authentication

## Project Structure

- `SportMate.API`: API endpoints and application entry point.
- `SportMate.Application`: Application services and business use cases.
- `SportMate.Domain`: Domain entities and business rules.
- `SportMate.Infrastructure`: Data access and external integrations.

## Development Notes

- Configure the required connection strings before running the application.
- Keep sensitive credentials out of source control.
- Run the API from the appropriate project directory.

## Maintenance

Backend documentation is maintained alongside the source code.
